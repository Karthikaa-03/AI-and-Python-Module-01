# Module 01 – Introduction to AI & Python

This beginner project contains:
- `Learning_Notes.md` – simple notes on AI, ML, Deep Learning, applications, and Python basics.
- `python_practice.py` – beginner-friendly Python examples for variables, loops, functions, and lists.

## How to use
1. Install Python 3 from the official Python website.
2. Open this folder in VS Code.
3. Open the terminal and run: `python python_practice.py`
4. Read `Learning_Notes.md` and practise changing the example values.
