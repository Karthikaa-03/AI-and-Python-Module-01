# Learning Notes – Introduction to AI & Python

## 1. What is Artificial Intelligence (AI)?
Artificial Intelligence is a field of computer science that makes computers perform tasks that normally need human intelligence. Examples include understanding language, recognising images, and making recommendations.

## 2. What is Machine Learning (ML)?
Machine Learning is a part of AI. It allows a computer to learn patterns from data and make predictions or decisions without being given every rule manually.

**Example:** An email service learns to identify spam messages from examples.

## 3. What is Deep Learning?
Deep Learning is a part of Machine Learning. It uses multi-layered neural networks to learn complex patterns from large amounts of data.

**Example:** Recognising objects in photographs.

## 4. Difference between AI, ML, and Deep Learning

| Term | Meaning | Example |
|---|---|---|
| AI | The broad field of making computers perform intelligent tasks | A voice assistant |
| ML | A part of AI that learns patterns from data | Spam email detection |
| Deep Learning | A part of ML that uses multi-layer neural networks | Image recognition |

**Relationship:** Deep Learning is part of Machine Learning, and Machine Learning is part of AI.

## 5. Real-world applications of AI
1. **Healthcare:** Helps analyse medical images and organise information.
2. **Education:** Supports personalised learning and doubt-solving tools.
3. **Banking:** Helps identify unusual transactions.
4. **Transportation:** Supports route planning and driver-assistance systems.
5. **Shopping:** Recommends products based on customer interests.
6. **Agriculture:** Helps monitor crops and identify plant problems.

## 6. Introduction to Python
Python is a high-level, beginner-friendly programming language. Its simple syntax makes it useful for automation, web development, data analysis, and AI projects.

## 7. Basic Python concepts

### Variables
A variable stores a value.
```python
name = "Karthika"
age = 18
print(name)
print(age)
```

### Data types
Common data types:
- `int` – whole numbers, such as `10`
- `float` – decimal numbers, such as `10.5`
- `str` – text, such as `"Hello"`
- `bool` – `True` or `False`

### Loops
A loop repeats a block of code.
```python
for number in range(1, 6):
    print(number)
```

### Functions
A function is a reusable block of code.
```python
def greet(name):
    print("Hello", name)

greet("Student")
```

### Lists
A list stores multiple values in one variable.
```python
subjects = ["Python", "Java", "AI"]
print(subjects[0])
subjects.append("DBMS")
print(subjects)
```
